 ⚡ Nova RP Helper

Внешний помощник для ролевой игры на **NOVA RP** (GTA 5). Справочник ~390 статей правил, биндер хоткеев с подстановкой `{ID}`, протокол наказаний IC/OOC, личные заметки и таймеры. Работает без модификации игры.

> ⚠️ Это **external-инструмент** — он не модифицирует игру, не читает память процесса GTA V и не внедряется в клиент. Вся работа идёт через эмуляцию клавиатурного ввода (`SendInput`) и глобальные хуки клавиатуры.



 ✨ Возможности

 🎯 Биндер команд
- Глобальные хоткеи с модификаторами (`Ctrl+Shift+F2` и т.д.)
- Подстановка `{ID}` цели во все строки
- RP-цепочки из нескольких строк с настраиваемыми паузами
- Очередь отправки через `SendInput` (антифлуд 40–90 мс)
- Защита от авто-повтора при удержании клавиши

 📖 Справочник NOVA RP (~390 статей)
- **Общие правила проекта** (аккаунты, чаты, RP-процесс, игровой процесс, системы, администрация)
- **Общие правила гос. структур** (LSPD, SAHP, FIB, NG, EMS, GOV, LI, USSS)
- **Уставы**: Правительство, LSPD, SAHP, NG (включая УСП и УКС), EMS, FIB (DIOG)
- **Мероприятия**: общие правила + отстранения + 8 ивентов (24/7, аммунация, банкоматы, клады, станок, Контроль штата, Взлом данных, поставки, инкассация)
- **Криминал**: похищения, ограбления, автоугоны, выкупы
- **Зелёные зоны** и регламент федеральной тюрьмы
- **Правила лидеров** организаций
- **Проверки на стороннее ПО** и списки разрешённых/запрещённых модификаций
- **RP-команды** с шаблонами `{ID}`

 ⚖️ Калькулятор наказаний
- Протокол из нескольких статей с автоматическим суммированием минут и штрафов
- Ручное переопределение срока/штрафа (прецедентная система п. 1.2 ОП)
- **IC-режим** → генерирует `/jail`, `/fine`, `/warn` с подстановкой Target ID
- **OOC-режим** → текстовая формулировка для деморгана/варна/бана
- Статьи категории «Уставы» всегда выдают текстовую формулировку (внутренние взыскания не шлются чат-командой)
- Журнал выданных наказаний с подписью выдающего

 📔 Личный журнал
- Заметки (сделки, долги, контакты)
- Бухгалтерия смены (приход/расход, баланс)
- Чек-лист смены (настраиваемый, с галочками)
- Всё сохраняется между сессиями

 ⏱ Таймеры и авто-пиар
- Быстрые таймеры (угон, аптечка, броня, капт)
- Авто-пиар с рандомизацией окончания (обход анти-спама)
- Настраиваемый интервал

 🪪 Ролевой профиль
- Регистрация при первом запуске: ник `Name_Surname` + роль
- Роли: Гражданский, Администрация, Гос. структура (с выбором фракции и ранга из устава), Нелегальная организация
- Бейдж роли в шапке оверлея
- Автоматический выбор режима наказаний по умолчанию (IC для гос/крим, OOC для остальных)

 🖥️ Интерфейс
- Полупрозрачный оверлей поверх игры (click-through по INSERT или авто по фокусу игры)
- Ресайз окна с запоминанием геометрии
- Dark Modern UI (Segoe UI, кастомные стили)
- Работает в Windows 10 19041+ / Windows 11 x64



 🚀 Установка

 Способ 1. Готовый релиз (рекомендуется)
1. Скачай `NovaRpHelper.exe` из раздела **Releases**
2. Запусти двойным кликом
3. При первом запуске пройди регистрацию профиля
4. Готово

 Способ 2. Сборка из исходников
Требования:
- Visual Studio 2022 (17.8+) с workload **.NET desktop development**
- .NET 8 SDK
- Windows 10 19041+ / Windows 11 x64

```powershell
git clone https://github.com/Pan1cxz/NovaRpHelper.git
cd NovaRpHelper
dotnet restore
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:PublishTrimmed=false -o ./publish
